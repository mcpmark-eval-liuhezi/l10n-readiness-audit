# l10n-readiness-audit

Localization readiness audit — pre-team-meeting status tracker for our localization push.

## What this is

A small readiness audit that lives on GitHub so the whole team can point at it before we kick off the localization of our project docs. It gathers the current state of our machine-translation workspace, documents it, and gives everyone one place to leave feedback.

## Scope

- **Translation side:** inventory of the glossaries currently configured in our machine-translation workspace (names + IDs), plus background reading on translation memory.
- **GitHub side:** this repository, an open tracking issue for teammate feedback, and a pull request that tracks the in-progress status of the audit.

## Where to leave feedback

Open the tracking issue titled **"Localization readiness audit"** and leave a comment. All input is welcome ahead of the team meeting.
